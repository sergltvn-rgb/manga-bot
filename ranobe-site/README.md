# Ranobe Radar 2026 — сайт-инфографика

Одностраничный интерактивный отчёт по онгоинг-ранобэ и веб-новеллам в жанре романтики, которые на май 2026 года **ещё не переведены на русский**. Составлен на базе аналитического отчёта и обогащён свежими данными с Kakuyomu, Scribble Hub, Royal Road, J-Novel Club и Yen Press.

## Как открыть

Достаточно открыть `index.html` двойным кликом в любом современном браузере (Chrome/Edge/Firefox). Интернет нужен — подтягиваются Tailwind, Chart.js, Lucide Icons и шрифты Google.

Если хочется запустить на локальном HTTP-сервере (например, чтобы не было ограничений `file://`):

```powershell
# в папке ranobe-site
python -m http.server 5500
# откройте http://localhost:5500
```

## Что внутри

- **Hero + KPI** — общая сводка по 73 тайтлам.
- **5 интерактивных графиков** — распределение по платформам, топ-10 по объёму, жанровая матрица, radar-сравнение, scatter «год × объём».
- **Каталог из 73 карточек** — фильтры по платформе, языку, контенту 18+ и приоритету перевода, модалка с подробностями.
- **Must-Translate топ-5** — экспертная подборка с индексом приоритета (0–100) и обоснованием.
- **Причины отсутствия переводов** — 4 фактора (объём, психологизм, stubbing, гибридность).
- **Источники** — все ссылки из исходного отчёта + новые.

## Файлы

- `index.html` — разметка страницы
- `styles.css` — тёмная тема, glass-эффекты, анимации
- `data.js` — данные тайтлов и платформ (редактируется вручную)
- `app.js` — рендер каталога, фильтры, графики (Chart.js)

## Источник и лицензия

Исходник — `Поиск онгоинг-ранобэ без русского перевода.md` (май 2026). Данные могут устаревать: платформы обновляются ежедневно, перед планированием перевода сверяйтесь по прямым ссылкам в карточках.

Сайт сделан как аналитический артефакт — не ведёт продажи, не хостит главы, не содержит чужих обложек (все визуалы — процедурные градиенты).
